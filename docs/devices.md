# Test devices

All measurements in this repository come from these two devices. Any other device is out of scope.

## Phone

- Model: OnePlus 11R 5G
- OS: Android 16
- RAM: 16 GB physical. The phone also has a separate 12 GB storage-backed "RAM extension". That extension is storage, not RAM, and no result here counts it as memory.
- Storage: 256 GB

## Mac

- Model: MacBook Air M4 (2025)
- Memory: 16 GB unified memory

## Out of scope

The project has no iOS device, so iOS is out of scope. The Flutter apps target Android and macOS only.

## Required ASR languages

- English
- Tamil
- Malayalam
- Hindi
- Tamil-English code-switching
- Malayalam-English code-switching
- Hindi-English code-switching

The evaluation script uses these language codes: `en`, `ta`, `ml`, `hi`, `ta-en`, `ml-en`, `hi-en`.
